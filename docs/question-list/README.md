## 四、防复踩（被推翻的旧结论，勿照旧推理改回去）

- **邮箱大小写口径**（#20，已修 `7087169`）：旧注释断言「按原样比较」——**不成立**，库是
  `utf8mb4_general_ci`（大小写不敏感）。新增任何以邮箱为键或为判据的逻辑，必须显式定义大小写口径。
- **「上集群补 hash tag 即可」不充分**：脚本要删的旧 at/rt 键名由 ARGV 拼出、从未出现在
  `KEYS[]`，集群会直接报错；真迁移需把键结构改成以 userId 为 hash tag 的形态并改客户端契约。
- **「绝对上限 30 天」的真实口径**：判定在轮换路径内，会话键 TTL 每次轮换续期 ⇒ 最久可存在
  约 36–37 天（不构成越权，但与字面承诺不符，排查时勿误判）。
- **「导出公式注入」已证伪**（#3）：结论与修法一并撤销；重新成立条件见 §三。
