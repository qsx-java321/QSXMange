## 测试类与断言点

| 测试类 | 关键断言点 |
| :--- | :--- |
| `AuthControllerTest` | 注册 / 登录 / 当前用户 / 改密（含参数校验） |
| `SessionLuaTest` | **唯一直连会话层**：三键形态与 TTL、单端覆盖、轮换失效、重放拒绝、并发双花、绝对上限（Redis 直连机制断言） |
| `MustChangePasswordTest` | **准入闸 1037**：初始口令账号除 `/auth/**` 外一律被拦；整前缀豁免（刷新 / 发本人码 / 登出 / me）；改密后自动解除；登录与刷新**不因该标志失败** |
| `AuthRefreshTest` | 严格轮换、旧 AT 立即失效、重放 1019、单端登录 |
| `AuthSessionTest` | 登出 / 禁用 / 删除后旧 AT 401 且三键清空、改密强制重登 |
| `SecurityAccessTest` | 401 边界、匿名放行、伪造 / 已吊销令牌 401 |

## 机制层断言（Redis 直查）

- 登录 / 刷新后 `qsx:auth:at:{at}`、`rt:{rt}`、`session:{userId}` 均存在且 TTL 合法（`SessionLuaTest` 逐键断言）。
- 登出 / 踢人 / 禁用 / 删除 / 改密 / 重置后三键删除 → 旧 AT 立即 401（证明「删键即吊销」，而非每请求查库兜底）。
- **刷新即吊销旧 AT**：`auth_session_rotate.lua` 第 5 步显式删除旧 AT 键（保留旧 AT 就是保留 30 分钟的踢人漏洞）。

## 保护与业务码落点（本域）

| 码 | 触发 |
| :--- | :--- |
| 1001 | 已注册邮箱注册 / 发 REGISTER 码给已注册邮箱（唯一性**先于**验证码校验） |
| 1002 | 登录密码错、邮箱不存在（同码防枚举） |
| 1003 | 登录已禁用账号 |
| 1006 | 改密通道 A 原密码错 |
| 1019 | 刷新令牌格式错 / 不存在 / 已轮换 / 已登出 / 用户被禁用（**空串会先被 `@NotBlank` 拦成 400**） |
| 1027 / 1028 / 1029 | 验证码发送过频 / 无效 / 错次超限（第 5 次错即作废） |
| 1030 | 忘记密码两次输入不一致（**先于**验证码校验） |
| 1031 | 改密两通道**都不传**或**都传** |
| 1032 | CHANGE_PASSWORD 场景发码给非本人邮箱 |
| **1037** | **待首次改密账号访问非 `/auth/` 接口**（HTTP 200 + body 1037；**先于 403**） |

> 1037 的判定位在 `TokenAuthenticationFilter`、与 `isEnabled()` 同一处：
> **已禁用**账号返回 **401 而非 1037**；`/auth/captcha`(CHANGE_PASSWORD) 未登录时因 URL 层 permitAll，
> 返回的是 **HTTP 200 + body 401**（业务层判定）。
